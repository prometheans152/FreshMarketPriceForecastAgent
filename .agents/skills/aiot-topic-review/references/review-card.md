# 候選題評估卡

短名單採用下列欄位；長清單可用表格壓縮，但保留資料來源、既有作品比較、差異與限制。

| 欄位 | 應提供的內容 |
| --- | --- |
| 題目／編號／狀態 | 保留原候選編號；候選、待查核、建議深入或使用者已選定。 |
| 用途與最低成果 | 哪位使用者在何種情境得到什麼可展示結果。 |
| 學習目標 | 模型輸入、輸出、真實標籤欄位；無標籤時描述學習方式及代理目標限制。 |
| 公開資料 | 原作者／機構、URL、版本、查核日期、授權、取得方式、規模、時間範圍與取樣頻率。 |
| 資料查核狀態 | 頁面、下載、實際樣本、模型訓練、本地測試分開記錄；舊快照與本次實測分開。 |
| 樣本適配 | 欄位與目標是否存在、缺值、資料量、國家／場景／感測器／語言差異。 |
| 代表性既有作品 | 可查證來源與日期；比較問題、資料、方法、評估，而不只看題名。 |
| 既有比較與保留理由 | 具體作品已完成什麼、本題多驗證什麼、已查範圍與未查部分；無實質差異者排除，不用高／中風險評語代替查核。 |
| 差異化假設 | 與哪個對照方案比，在何種條件下期待何種可量化改善；是否仍需確認新穎性。 |
| 個人化／公開限定 | 自家資料如何收集、標註、校正及獨立驗證；不用個人資料時如何形成可測量特色。 |
| 最小驗證 | 一個簡單基準、主要指標、分組／時間切分、防洩漏與失效情境；以實測決定可行性。 |
| 課程符合度 | 模型、分析、使用情境與需釐清的代理人／交付要求，引用原來源。 |
| 限制與下一步 | 最關鍵瓶頸、取得成本、證據缺口及可立即進行的小步驟。 |

完整卡以來源為依據。未知授權、未讀標籤、未完成查重、未驗證個人化的欄位，直接說明未知程度；不要補寫成已完成。
