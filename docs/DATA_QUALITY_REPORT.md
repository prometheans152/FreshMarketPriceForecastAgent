## 排除決策（凍結）

1. **(停)建國市場排除**：名稱含「(停)」、全期 1,062 列中甘藍沿用價 run 密集（最長 44 天），非有效觀測。排除 1,105 列長表列（三品項合計），規則凍結於 `scripts/prepare_data.py`，理由＝停用＋沿用價，與測試分數無關。
2. **南屯市場甘藍**：覆蓋 0%，自然無法產生標籤/特徵，不刪除來源資料，由「特徵不足→insufficient_data」路徑處理。
3. **第二市場**：僅 127 個觀測日（覆蓋期短），保留；其列只出現在部分切分區，屬正常時間切分行為。
4. **價格合理範圍**（輸入 sanity，供 API）：以訓練區 1%/99% 百分位為描述基準（甘藍 14–85、青江白菜 20–80、絲瓜 23–72 元/斤）；上下界外不拒絕但標警告，極端值由人工覆核規則把關（`configs/project.yaml price_sanity`）。

## 對切分與模型的影響

- 排除 (停) 市場後 13 市場；時間切分統計（train 2025-10-04～2026-05-08、validation 2026-05-10～2026-07-21、test 2026-07-22～2026-10-02）見 `prepare_summary.json`。
- 發布延遲實測未完成：保守假設「觀測日+1 可見」（`LabelConfig.publish_delay_days=1`），t 當日市場價不作 t 日推論特徵；日後實測更新需記錄並重跑敏感度。
- 跨市場同日列屬相關觀測：評估以時間切分為單位，不把 4,000+ 列當獨立樣本。
