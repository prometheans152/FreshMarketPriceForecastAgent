## 關鍵不變量（測試釘死）

1. **來源舊不退回起點**：公開歷史截短至 09-25、查詢 10-02 時，target_date 仍為 10-09／10-16（從使用者今天算），附天數警示（`test_stale_history_does_not_shift_origin`）。
2. **歷史日期 as-of 特徵**：以 5/1 查詢時，特徵只用 5/1 前可見資料（發布延遲 1 日）。
3. **B 一律標實驗性**：所有 B 輸出含「實驗性規則」警示與 `validation_scope=unvalidated`。
4. **機率/區間不輸出**：未校準，一律 null。

## 已知錯誤型態（來自封存測試逐列分析）

- **up 類召回率低**（h=7 約 10%、h=14 約 9%）：模型偏保守報 flat；「上漲」敏感度有限是本版最大能力限制，回應措辭不得暗示能可靠抓漲。
- **點估計 MAE 未優於不變價基線**：相對變化點估計僅供參考（每個結果都帶此警示）。
- **甘藍方向事件少**（macro-F1 最低 0.31）：多數期間持平，up/down 樣本不足。
- **只支持臺中市場均價**：不外推其他城市；市場均價≠單店真值。

## 邊界外（明確不做）

- 預測漲價→保證囤貨省錢的建議（系統只給方向與估計，不給消費建議保證）。
- 跨年度／颱風災害行情泛化（僅一年資料）。
- 同店 A/B 效果宣稱（T16 HOLD：缺真實同店到期價）。
