## 狀態與證據規則

TASKS.md是任務狀態的主要來源；[GLM_PROGRESS.md](GLM_PROGRESS.md)記執行過程與最新進度，不另造互相衝突的全套任務編號。

| 狀態 | 意義 |
| --- | --- |
| TODO | 尚未開始 |
| DOING | 正在處理，未通過驗收 |
| PASS | 該項明列的產出及驗收證據成立，附具體引用 |
| FAIL | 已測試但驗收未通過，保留失敗和修復紀錄 |
| HOLD | 等到期店價、資料成熟、公告或必要主機資訊等外部依賴，不能算已完成 |
| BLOCKED | 該任務的執行路徑受阻且無法續做，說明原因、依賴與其他可繼續部分 |

每次交接記錄：

```text
TASK：Txx及名稱
狀態：
主機：TRAIN_LOCAL或SERVER_3090
輸入／依賴及版本：
實際命令／操作與環境：
產出路徑與必要hash：
驗收結果與證據：
已知限制／未驗證：
下一個可執行TASK／真正所缺資訊：
```

常規本機安裝放專案隔離環境，不改無關專案或全域配置。個人原始資料、權重、憑證、完整執行日誌與大型資料保留本機忽略目錄；可交付匿名彙總與重現方法。技能若不在GLM環境中，以本案文件和實際工具完成，不因缺少Codex插件停工。
