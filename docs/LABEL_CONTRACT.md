# 7／14 天標籤契約（T07）

建立日期：2026-10-03。實作：`src/aiot_price/data/labels.py`；測試：`tests/data/test_labels.py`。本契約在凍結測試清單後不得改變口徑；任何調整須記錄於 DECISIONS.md 並重驗受影響工件。

## 口徑定義

| 項目 | 定義 |
| --- | --- |
| 起點 t | 查詢當下的臺灣日曆日（使用者今天），不是公開資料最新日 |
| 目標日 | t＋h 日曆日，h∈{7,14}；**精確日期配對**，缺該日資料不得以前後日暗替 |
| 配對條件 | 同市場、同品項，t 與 t＋h 兩端皆為**正價格**（元/台斤） |
| 回歸標籤 | `r_h = m(t+h) / m(t) − 1`（相對變化） |
| 方向標籤 | `r_h > +5%` → up；`r_h < −5%` → down；`\|r_h\| ≤ 5%` → flat（門檻凍結於 D34） |
| 缺標籤 | 目標日無正價格（0＝無價、缺列）→ `insufficient_data`；**缺標籤不是「未漲」** |
| 標籤成熟 | `label_mature_at = 目標日 + publish_delay_days`；發布延遲實測前保守假設 1 日，實測後更新並記錄 |
| 適用範圍 | 本契約只定義**公開市場均價**標籤；同店實價標籤另依 `configs/store_record_schema.json` 的到期回填建立，兩者不得混用 |

## 手算例子（測試固定案例）

| 案例 | m(t) | m(t+7) | r_7 | 方向（±5%） |
| --- | ---: | ---: | ---: | --- |
| E1 中義市場 甘藍 2025-10-04 → 2025-10-11 | 27 | 25 | 25/27−1 = −0.0741 | down |
| E2 持平邊界：30 → 31.5 | 30 | 31.5 | +0.05 | flat（≤5% 含） |
| E3 剛超門檻：40 → 42.1 | 40 | 42.1 | +0.0525 | up |
| E4 目標日 0（無價） | 42 | 0→NaN | NaN | insufficient_data |
| E5 目標日超出資料範圍 | 30 | 無列 | NaN | insufficient_data |

E2/E3 驗證邊界值數學：31.5/30 = 1.05（r=+0.05，≤5% → flat）；42.1/40 = 1.0525（r>0.05 → up）。

## 防洩漏約束（供 T08 切分引用）

- 訓練案例的 `label_mature_at` 必須早於驗證切分起點；驗證案例的成熟日必須早於最終測試開始。
- 特徵只能使用 t（含）之前**已公布**的資料；`publish_delay_days` 同時約束「t 當日價可否作特徵」（觀測日＋1 才可見 → t 當日市場價不可作為 t 日推論特徵）。
- 同日多市場為相關觀測；切分以日期為單位（T08）。
