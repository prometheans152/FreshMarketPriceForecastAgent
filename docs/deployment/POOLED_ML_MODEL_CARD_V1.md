# TW01｜57 品項監督式 ML 模型卡

版本：multi-crop-ml/1.0.0。日期：2026-10-15。

**此版已真正完成監督式 ML 訓練和獨立測試集評估，但測試誤差尚未勝過最簡單的不變價基準。**

## 研究目的與資料

目標：以臺中市公有零售市場同市場、同品項的歷史正價格，學習觀測基準日 t 到 t+7、t+14 日曆天的市場均價相對變化。實際預測以使用者提供的現場店價乘上模型預測的市場相對變化。這不是實際店家到期真價驗證。

來源：臺中市政府每日蔬果價格，data.gov.tw/84539；原始資料 4450 筆市場日期紀錄、61 個價格欄、13 個有效市場，日期 2025-10-04 至 2026-10-02。61 欄含蔬菜 15、水果 27、魚海鮮 7、肉 10、蛋 2。牛心柿全 0，依資料定義是缺測，不列入模型。

保留原高麗菜、青江白菜、絲瓜三品項的 v0.1.0 正式 RF(7天)/HGB(14天) 模型、權重、資料與 MCP API。另對 57 個有正價格的品項共同訓練**兩個新的 HistGradientBoostingRegressor (HGB)**，各對應 7／14 天期限。這是 supervised pooled regression，不是將舊模型強行套在未知品項，也不是單純過去漲幅延續規則。

## ML 設計

- 標籤：log(同市場品項 m(t+h) / m(t))，t 和 t+h 均須實際有正價格。絕不把 0、缺日或其他交易日當真實目標價。
- 特徵：可見最新價的對數、資料距今多久、7/14/28 日歷史均價比、14 日價格波動、過去 7/14 日變化、有效價格筆數、星期、月份、品項和市場 One-Hot 編碼，共 83 維。
- 避免資料洩漏：每個 t 的特徵只讀 t−1 日或之前的價格；1 日發布延遲屬保守假設，尚未做實際公布延遲的獨立驗證。單元測試擾動未來行情，特徵保持不變。
- 固定隨機種子 42。以時間切分、不做隨機逐列切分。訓練 t 截至 2026-05-08；驗證 2026-05-09 至 2026-07-21；測試自 2026-07-22 起；t+h 標籤成熟加 1 日後不得穿越下一時間區間，並執行 purge。
- 驗證階段比較 Ridge 與 HGB 的相對變化 MAE，7/14 天都選擇 HGB；使用訓練與已成熟驗證樣本 refit 後，**留出測試集未參與選模**。
- 以公開市場漲跌方向 ±5% 分 up/flat/down；無已校準機率或預測區間，統一回傳 null。B 模式維持固定實驗規則 α=0.3，並非另外訓練的 B 模型。

## 公開市場時間留出測試

| 指標 | HGB 7 天 | HGB 14 天 |
| --- | ---: | ---: |
| 原始訓練列數 | 74,597 | 71,682 |
| 驗證列數 | 23,446 | 20,882 |
| refit 列數 | 98,043 | 92,564 |
| 獨立測試列數 | 25,173 | 22,396 |
| HGB 相對變化 MAE | 0.02124 | 0.03130 |
| 不變價基準 MAE | **0.01163** | **0.02085** |
| 歷史動量基準 MAE | 0.02121 | 0.03685 |
| HGB 方向 Macro-F1 | 0.37774 | 0.41474 |

MAE 愈小愈好。**這兩個真正訓練過的 ML 模型在這份留出測試上都沒有勝過不變價基準。** 7 天略遜動量基準、14 天勝過動量基準但仍不如不變價。這是誠實的 ML 課程研究結果，不能因上線就宣稱準確度提高。

其餘研究限制：公開市場資料並非單店真值；來源有沿用價、漲跌不平衡或季節性變動的可能；只有約一年觀測資料；尚未驗證跨年度、極端天候或模型調整後的全新未見資料。原三品項的舊測試母體不同，與新 57 項模型指標不可直接橫向推斷優劣。
