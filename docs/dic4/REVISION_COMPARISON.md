| 主題 | 修改前 v1 | 修改後 v2 |
| --- | --- | --- |
| 文稿性質 | 可編譯的精簡設計提要 | 學術式研究問題、方法、結果、限制完整章節 |

| Results | 數字與基線簡述 | 表格附 n／macro-F1／return MAE／上漲 recall、明示低於基線 |
| Evaluation | 未來要驗證 | 同店同品項到期配對、凍結預測、缺值和失敗情境 |
| Submission | 本機初稿 | Overleaf 可匯入 ZIP，需雲端編譯與驗證 |
