# 保留候選 N18：臥室清晨最低溫與發生時間

記錄日期：2026-10-03。

**狀態：使用者明確要求「18保留」；保留供後續比較，尚未定題。** 原編號N18不變。TW01菜籃費用亦保持暫存。使用者接著要求繼續找其他題目，增加工作用途，並表示先看各類工作。

## 用途與日常輸入

睡前預估自家臥室到清晨的最低溫及發生時間。首次設定房間與溫度記錄；平時睡前填「窗戶開／關、冷氣有／無」，室溫由感測器自動記錄。

這是前輪提出的使用流程，保留題目不表示使用者已接受設備、模型或操作方式。

## 公開模型基底與家庭真值

- [台灣氣象署歷史觀測](https://codis.cwa.gov.tw/StationData)可訓練外氣溫未來時序；**公開測站溫度不是自家臥室溫度標籤**。
- 最終家庭標籤為同一房間每晚的實測最低溫、發生時間，須另收室溫。
- 前輪已查[2021台灣30戶室溫估計](https://pmc.ncbi.nlm.nih.gov/articles/PMC8156969/)；已有室外天氣、建築與行為估室溫。本題限定睡前可用資訊，驗證整夜低點與自家熱延遲，不能把一般室溫預測當首次。
- 本筆記承接2026-10-03前輪資料查核，本次未重新下載氣象或家庭資料。

## 保留的比較構想

比較外氣最低溫直接套用、固定室內外溫差、簡單熱模型、公開外氣模型加家庭殘差。以3／7／14晚校正，按整晚留出，測最低溫誤差、時刻誤差及開窗／關窗情境；不能使用隔天實測天氣作睡前輸入。

原採集建議是2–4週自動室溫與每日一次狀態。這只是小型案例的起步建議，未證實足夠；使用者設備與可投入時間仍未指定。
