# G清單新發想題查核（21題）

查核日期：2026-10-03。本檔記錄本輪獨立發想的新候選題（非U清單重列）之資料實測與前作查重。查核方式：代理人以 WebFetch／curl 實測資料頁與下載端點，WebSearch 查前作；關鍵連結由主對話覆抽。本檔是選題研究紀錄，不代表任何模型已訓練或家庭效益已驗證。

環境限制（如實記錄）：本日 WebSearch 多次限流（429），部分前作僅取得搜尋摘要層證據，已逐項標注；data.gov.tw 全站搜尋頁當日回 HTTP 500，全國級資料集頁無法逐一開頁；CWA 開放資料 API 實測 401（需免費 CKEY），觀測類樣本層驗證待金鑰。

## 判定摘要

| A12 | 淹水／積水警戒 | 淘汰 | 歷史感測值可下載性未證實＋水利署/NCDR官方已營運同任務。 |

| B2 | YouBike可借可還預測 | 淘汰 | 77個月租借紀錄公開且多人發表站點級預測；個人租借紀錄對群體動態模型近乎零增益。 |
| B3 | 路邊停車格搜尋 | 淘汰 | data.taipei全站比對無開單歷史、無格位時間序列，訓練資料不存在。 |
| B4 | 捷運出發時段擁擠 | 淘汰 | 小時級進出量資料已被多篇論文直接用於同任務；「延後15分鐘」無資料解析度且屬應用包裝。 |
| B5 | 路線平整（坑洞）建議 | 淘汰 | 各直轄市均無坑洞修補紀錄開放資料集（全站標題比對0筆）。 |
| B7 | 通勤空汙曝險比較 | 淘汰 | 台灣團隊已用實測（非站點代理）發表運具比較結論；重做只剩更粗標籤。 |
| C1 | 台灣食物照片辨識 | 淘汰 | 候選Kaggle集標籤品質未證實；Food-101系與個人化食物分類前作已覆蓋兩半，剩介面差異。 |
| C2 | 藥品外觀辨識 | 淘汰 | 官方資料極佳（6,345筆、99.7%帶照片URL）但台灣屬性比對已有「藥會辨」、照片比對已有ePillID。 |
| C3 | 藥名→ATC成分分類 | 淘汰 | 官方藥名↔ATC對照本身就是可下載查表，精確查表基線即解決，模型無任務空間。 |
| D1 | 視訊坐姿提醒 | 淘汰 | 無可下載的webcam駝背細類標籤集；產品紅海（BLiiNK、Upright!等）。 |
| D5 | 手機床墊睡眠分期 | 淘汰 | 公開資料在手腕域、產品已占床墊域（Sleep as Android），兩頭被占無可測新點。 |
| D6 | 螢幕中斷模式 | 淘汰 | 可打斷性預測是20年以上密集文獻線；公開資料無中斷事件標籤。 |
| P1 | 寵物行為辨識 | 淘汰 | 最完整公開集80GB表單申請且為野生動物域；少樣本自訓正是DeepEthogram核心功能。 |
| P2 | 舊照片年代排序 | 淘汰（台灣適用性不足） | 訓練集全為美國/Flickr照片，服裝沖印文化特徵恰是最不可遷移部分。 |

## 各題查核證據

### A1 颱風假機率預測（→G02）

- 資料：人事行政總處「歷次天然災害停止上班上課訊息」歷史查詢（官網首頁→民眾專區→停班停課；直接連 `/typh/` 回403擋爬蟲，2026-10-03間接證實頁面存在）；地方彙整如[高雄市停班課專區](https://kpd.kcg.gov.tw)。CWA[颱風資料庫](https://rdc28.cwa.gov.tw/TDB/)本輪主對話實測HTTP 200、含「颱風資料庫」內容；CWA觀測API需CKEY（401實測）。
- 後續查重修正：已查到[2023開源模型](https://github.com/kxykxyou/TyphoonDayoffPrediction)、[2024學生颱風假預測](https://sciexplore2024.colife.org.tw/work/2024/C0089/pdf)、政大決策機率／門檻情境研究與[機率工具](https://typhoon.sectools.tw/)。一般「明天機率＋依據」已有前作，助理撤回原一般版推薦；詳見[G02／G41重查](G02_G41_RELATED_WORK_RECHECK.md)。
- 原差異依據撤回：原文0.322是Cox–Snell pseudo-R²，不是準確率或模型上限；「決策雜訊天花板」的推論沒有足夠依據。事件切分／校準是待核對的嚴謹實驗條件，不能憑本輪未見整套設計便宣稱新穎。
- 限制：歷史紀錄是網頁查詢非現成CSV需自行整理；每年正樣本個位數到十幾次；颱風季近尾聲，學期內未必有即時事件可示範；無個人化資料可用。

### A2 曬衣乾燥預測（→G01）

- 資料：[CWA氣象開放資料平臺](https://opendata.cwa.gov.tw/index.aspx)局屬測站逐時觀測（O-A0003-001：溫度／相對濕度／風速／降水／日照）頁面可讀，API需免費CKEY（401實測，樣本未讀）；歷史深度待CKEY後確認。
- 前作（皆感測器現場方案）：Arduino雨感自動收衣（JIDMIS）、UTAR感測晾衣架、Bohrium烘衣機軟感測ML——無人以「公開測站氣象＋家庭回饋」做預報式（早上曬、幾點收）乾燥預測。
- 差異：固定門檻規則（RH<70%且無雨）vs純公開資料模型vs＋2–4週自家乾燥紀錄校正；指標用「建議收衣時間的誤差」與「未乾誤報率」。
- 限制：陽台微氣候與測站差異由自家紀錄吸收；觀測欄位完整性待CKEY實測。

### A5 病媒蚊誘卵指數（→G04）

- 資料（樣本已讀）：[data.gov.tw臺南市登革熱誘卵桶監測](https://data.gov.tw/dataset/128442) CSV實抓23.8KB、511列，欄位＝縣市別／行政區／監測週期／陽性率／總卵粒數；同一欄有`0.0625`與`15.10%`兩種格式需清理。資料按月拆多個dataset（[156277](https://data.gov.tw/dataset/156277)、[139594](https://data.gov.tw/dataset/139594)）需合併。疾管署全國版未找到。
- 前作：北醫Kuo CY 2024登革熱預測（預測病例）；3D列印誘卵桶SARIMA+RF蚊量預測（2025）；台南市陽性率≥60%連兩週門檻規則（市政規則系統）。
- 差異：前作多預測病例；「區級誘卵指數短程預測＋家戶行動建議」較少見。
- 限制：限臺南、區級粒度；冬季指數低季節性極強，學期內正樣本少；個人化僅自家里／區查詢，採集卵粒不實際。

### B1 通勤路線事故曝險（→G03）

- 資料：全國A1/A2逐案資料以申請制為主（道安資訊平臺僅統計快覽）；**臺中市警察局「每月交通事故逐案資料」（A1+A2、CSV）已確認存在**（data.gov.tw／[opendata.taichung.gov.tw](https://opendata.taichung.gov.tw)及鏡像，104年起），欄位對照表可由交通大隊頁下載；單月檔偏大，樣本未讀。data.gov.tw搜尋頁當日500，全國集頁待修復後補驗。
- 前作：[主計總處高雄機車行人事故探勘](https://ws.dgbas.gov.tw/001/Upload/463/relfile/10315/2315/431f3800-fa0e-435b-a9c2-8910fcbfb8f1.pdf)、運研所高風險路段AI探勘計畫、[GIS肇事地點分析碩論](https://ndltd.ncl.edu.tw/handle/85263052710198418103)——全是全市熱點／風險排序／肇因分類；「個人起訖路線→時段別沿線曝險→替代建議」未見相同作品。
- 差異：規則基線（沿線歷史事故密度）vs時段×路口事故率模型vs＋自家GPS軌跡個人加權。
- 限制：實質限臺中起步；事故次數缺車流量分母，「風險」嚴格說是曝險量代理；GPS軌跡採集2–4週。

### 其餘淘汰題關鍵證據

- **A6**：CWA平臺無預報值歷史存檔（API為即時/未來值，歷史預報走tacc申購）；自建存檔期末前僅數週不足校準統計。
- **A8**：返潮無公開標籤；物理規則（露點>表面溫）可算但學不到自家牆體熱慣性；正樣本在2–4月。
- **A12**：水利署openData頁可讀但無淹水感測歷史可下載證據；NYCU/NTU淹水預測研究與官方警戒系統已營運。
- **B2**：[臺北市YouBike2.0租借紀錄](https://data.taipei/dataset/detail?id=c5924c17-25db-4f1e-99c4-f8ada40f2445)索引已讀（77個月、每月111–133MB ZIP）；YouBike調度/需求預測已有多篇（MDPI 2025等）。
- **B3**：data.taipei全站21,694筆標題比對「開單0、地磁0、剩餘格位0」；SFpark式研究全依賴感測器歷史，台灣無同等開放資料。
- **B4**：[臺北捷運分時進出量](https://data.taipei)（2015-11起小時級，2016-11月檔415KB已讀）已被Wu et al. 2023（PMC9892681）等多篇直接用於同任務；小時粒度無15分鐘解析度。
- **B5**：data.taipei「坑洞0、巡查0、平整0」；新北WAF擋、臺南SPA改版，未找到任何縣市可下載坑洞CSV。
- **B7**：環境部[空品小時值_縣市_站](https://data.moenv.gov.tw/dataset/detail/AQX_P_264)存在（API需key）；但環保署臺北都會區通勤暴露調查與國衛院2017已給實測結論（機車最高、各運具倍數），站點代理重做無差異。
- **C1**：Kaggle `kuantinglai/taiwanese-food-101`（3.9GB、GPL2、description空、標籤清單未證實）；Food-101／DeepFood／arXiv:2309.08744個人化食物分類覆蓋任務兩半。
- **C2**：[藥品外觀資料集](https://data.gov.tw/dataset/9120)實測6,345列、99.7%帶官方照片URL（樣本已讀）；但[藥會辨](https://magicakimo.github.io/pill-identifier/)已用同資料做屬性比對、[ePillID](https://github.com/usuyama/ePillID-benchmark)已定義照片比對基準。
- **C3**：[ATC碼資料集](https://data.gov.tw/dataset/9119)實測80,584列＋[許可證主檔](https://data.gov.tw/dataset/9122)可串成官方對照表——查表即得，模型無空間；ATC NLP/LLM前作（arXiv:2101.11713、2412.07743）已到78%完全匹配。
- **D1**：Kaggle剪影集僅4粗類；SitStraightNet「data on GitHub」實查僅10張樣本JPG；SitPose未公開；BLiiNK/Upright!產品已做webcam駝背提醒。
- **D5**：[BIDSleep(PhysioNet)](https://physionet.org/content/bidsleep-dataset/)手腕域ODC-By存在；Sleep as Android正是手機床墊加速規分期產品。
- **D6**：StudentLife官網連線失敗（僅Wayback佐證），且EMA是情緒量表非中斷事件標籤；Turner 2017／Mishra 2021／Pielot「Dismissed!」已密集研究。
- **P1**：[Animal Kingdom](https://github.com/sutdcv/Animal-Kingdom) 80GB表單申請、野生動物域；[DeepEthogram](https://elifesciences.org/articles/63377)核心就是自家少樣本訓練。
- **P2**：HCI年代集為美國照片；DEW（arXiv:2106.05618）百萬張Flickr無地理文化討論；年代估計是成熟benchmark。
