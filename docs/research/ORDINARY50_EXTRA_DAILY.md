## 共用資料證據：臺灣 iNaturalist 歷史觀察

- **來源／版本**：[iNaturalist API v1 文件](https://api.inaturalist.org/v1/docs/)、[公開下載方式](https://help.inaturalist.org/en/support/solutions/articles/151000170342-how-can-i-download-data-from-inaturalist-)與[開發者月度匯出](https://www.inaturalist.org/pages/developers)。本次使用 v1 JSON 的小頁查詢，不是固定發布版資料集。查核日與觀察 ID 是本次快照；補註、撤照、物種修訂會改變以後查到的數量。保存後續實驗 manifest、JSON 及雜湊才可凍結訓練版本。
- **臺灣範圍與時間**：`places/autocomplete?q=Taiwan` 實讀取得行政層級 0 的 `place_id=7887`。使用 `d1=2020-01-01`、`d2=2024-12-31`、`quality_grade=research`、`photos=true`。這是 2020–2024 **observed_on** 的歷史紀錄；不得把 2026 年才上傳的舊觀察按上傳年切分。
- **授權**：查詢同時設 `license=cc-by,cc0` 與 `photo_license=cc-by,cc0`。[官方授權說明](https://help.inaturalist.org/en/support/solutions/articles/151000173511-how-do-licenses-work-on-inaturalist-should-i-change-my-licenses-)明確區分觀察紀錄、照片與聲音授權；各照片保留 `license_code`、`attribution`、來源觀察及 URL。CC BY 照片須標作者與授權，CC0 依原聲明；不把物種 `default_photo` 混進訓練，因為其授權可能與所選 observation photos 不同。[照片使用說明](https://inaturalist.freshdesk.com/en/support/solutions/articles/151000169918-can-i-use-the-photos-and-sounds-that-are-posted-on-inaturalist-)另有原圖取用與權利提醒。
- **原欄位**：`id`、`observed_on`、`time_observed_at`、`created_at`、`user.id`、`taxon.id/name/rank`、`quality_grade`、`license_code`、`place_guess`、`geojson`、`geoprivacy`、`annotations[].controlled_attribute_id/controlled_value_id/vote_score`、`photos[].id/url/license_code/attribution`。保留原欄位，不把中文展示名稱當另一套標籤。
- **取樣頻率**：民眾自主上傳，沒有固定日頻率；API 返回歷史記錄。GBIF 匯出為[每週更新](https://help.inaturalist.org/en/support/solutions/articles/151000170346)，開發者開放照片資料為月度快照。地點可能模糊／遮蔽，時間精度可能不足；無法據此取得同一實體植物連續多日的真值。
- **標註強度**：`research` 是物種辨識品質條件，不能推成花果註記已由專家複核。`annotations` 是觀察層級人工記錄，同次觀察可能有多張照片；未註記不代表無花，單張未拍到不代表整株無花，`vote_score=0` 也不是已取得多數專家同意。公共分組單位至少是原 observation，而非 photo。
- **實際取得狀態**：來源頁、API JSON 回應成功，原欄位與小頁標籤已讀；5 張 medium 圖片在記憶體檢讀。沒有取全量原圖，沒有保存私人資料、訓練模型或在家驗證。以下只描述候選實驗。

| 限制與下一步 | 不是植物健康、病害、水分、養護或來年開花預報；不能用照片判斷沒有拍到的花一定不存在。花與果可能同時存在，不能強制單向花→果或禁止重新開花。若只有 1 盆或沒有可持續花期變化，私人獨立測試不足。下一步是先用 2 盆、7 天試點驗證能否可靠定義 whole-plant 真值與三個動作；此處尚未執行。 |

| 個人化／公開限定 | 每種 6 盆，共 18 個實體盆株；2 盆／種作校正、4 盆／種只作測試。用種子包、播種表與獨立盆 ID 作真值，拍照時遮掉標籤文字、使花盆顏色與種類不一對一，背景隨機交換。幼苗拍 3 次不同成長天數，約 2–3 週；成熟株比較需已有同種成熟株，或另外等待長成，不能用同一幼苗將來照片回灌它自己的測試。沒有成熟株時先完成 A／C 的試點，B 未完成就不能宣稱完成全部差異驗證。 |
| 最小驗證 | 公共資料所有同 observation 照片共組，去近重複並按 observer／地點／觀察年月補做保留組；類別不平衡須用 macro F1／逐類召回，不靠高比例青葙與含羞草掩蓋紫茉莉。私人按實體盆株分組、另一播種批次或較晚生長日期與換光線作外測。以 12 個完全未校正盆作初步盲測，重拍圖不能算新盆。報 macro F1、未知物種誤認比例、拒答覆蓋率與每盆照片／秒數；另外加入不在登記清單的普通草苗作拒答測試，真值不明的雜草僅標「非已播種三種」，不硬指定物種。樣本規模只適合試點，不作所有臺灣幼苗可靠性宣稱。 |
| 課程符合度 | 公開 true taxon 可訓練模型，個人來源／生長階段比較有分析目標；代理人可讀已登記種子清單與照片帳，顯示既有真值對照，遇未知者要求保留或稍後重拍。[課程證據](../COURSE_REQUIREMENTS.md)沿用模型與代理人確認程度。 |
| 限制與下一步 | 不是所有幼苗、栽培品種、雜草名稱或農作拔除決策；只有公共成熟株圖也不能宣稱已會辨幼苗。鳳仙花同條件僅 4 次、百日草與辣椒查到 0 次，這些不硬列有充足臺灣訓練來源。下一步先核種子包學名與願意保留的盆數，再拍每種 2 盆的子葉／真葉試點；目前私人種子、照片與栽培條件都未取得。 |
