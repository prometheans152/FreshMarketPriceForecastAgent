# 一般人的基礎計算複習候選

查核日期：2026-10-03。L01 是本輪候選，不是已選題，也沒有訓練或學習效果驗證。此題取用既有資料查核的證據，改成普通成人練習基礎計算的使用情境；不是把使用者撤下的 W01–W50 再推薦。

## L01｜基礎計算容易忘，下次只複習最需要的三個單元

- **用途／最低成果：** 願意練基礎計算的一般人，輸入自己的短練習紀錄；當天只排最多三個需要再練的單元，尤其避免提示後答對就被誤判已熟練。不處理公司業務、學生成績或考試保證。
- **公開資料／實讀狀態：** [台灣均一 v9 正式來源](https://www.kaggle.com/datasets/junyiacademy/learning-activity-public-dataset-by-junyi-academy)，2018/08–2019/07、16,217,311 次作答、作者選取 72,630 位學生、CC BY-NC-SA 4.0；選定後遵守署名／非商業／適用衍生資料同授權。下載免登入，3 GB 作答表不整包下載。本輪 [辦公分支來源 D7](ORDINARY50_EVERYDAY_OFFICE.md)重讀 ZIP 首段表頭與兩筆，耗時 33／8 秒、提示 0、一次嘗試及真 `is_correct`。內容表的 389,397-byte CSV、標題／ucid／難度／學段／分類證據承接同日 [TW_MORE_PERSONAL](TW_MORE_PERSONAL.md)，該檔有「【基礎】和差問題1」；**沒有完整題幹，不承諾自動出題或解題。** 折扣／百分比的內容單元是否足量須選中後再計數。
- **模型與真值：** 用目前以前的 `uuid,ucid,upid,is_correct,used_hint_cnt,total_attempt_cnt,timestamp_TW`，預測之後至少隔一天、同 `ucid`、該人之前從未做過的 `upid`、無提示／第一次嘗試的正確性。`ucid` 僅是練習單元，不能一概叫精確概念；沒出現後續紀錄是缺標籤，不是答錯。這是派生作答表現，不是直接測熟練度。篩無提示會有選擇偏差，要報覆蓋率；當前事件不能偷看未來提示、結果或日期。
- **已有人做什麼：** [CPKT 作者實作](https://github.com/persai-lab/CIKM2023-CPKT)已有個人化、長期學習／遺忘追蹤；[均一時序預測](https://github.com/rizalfanex/junyi-temporal-learning-prediction)已有下一次作答模型；[MC-CPO v2](https://arxiv.org/html/2604.04251v2)已處理答對與熟練不一致及教學策略。這三個來源本輪重新開啟核對。不能用「個人化」「答對不等於學會」作新穎性主張。
- **本題另測什麼：** 在個人很少練習紀錄與每天固定三單元額度下，以**隔日從未做過的新題獨立答對**作為排序目標；對照最近答對率、一般下一題模型及該延遲目標模型。測被排除複習卻在延遲新題失敗的比例、三名額涵蓋失敗單元的數量及機率校準，另分提示後答對／獨立答對。不能從離線順位就宣稱複習改善學習，實際改善另需前後介入或交叉試驗。
- **一般輸入／成本與獨立測試：** 願意練的人，3–4 週約 20–50 次短練習，記單元、題 ID、是否用提示／一次答對及日期；可自行核對合法題目，不強求提供帳號。公共按人切，私人按日期切，重複同題不跨組；後續新題按人、單元及完整學習時間線判定未見。這是試點規模，不是證明學習效益足夠的樣本數。
- **台灣適用及限制：** 公共是台灣學生，不是假稱成人上班族資料；成人基礎計算及現在題庫對應需私人試驗。若使用者不願練，或隔日未見新題標籤不足，此題撤下，不能偷偷改回普通下一題預測。與 EO14「做得完幾題」不同：此題分配複習名額，目標為延遲獨立成功，EO14是耗時。資料欄位實讀、派生標籤尚未全表計數、模型及私人結果未驗證。
