## 原保留 F01：固定菜籃的家庭零售價差校正與費用預估（歷史）

整合審查縮小承諾：主要成果是家庭實付價校正前後的費用誤差；預算區間與超支提示是探索成果。12–16次採買、4–6次獨立測試只支持小型案例，報「幾次測試中涵蓋幾次」，不承諾穩定區間覆蓋率或超支漏報率。公開多年批發測試與家庭短期零售試點分開；紀錄必須有可比品種、品質、通路及重量。

**用途／最小成果**：使用者列出固定的 3–5 項蔬果及公斤數，系統預估下一次採買合計的金額區間，並指出哪些品項使預算上界增加。先限固定市場與通路、固定品種，避免泛稱全部菜錢或全家所有食品支出。

**真實學習目標**：公共模型用截至預測當日的作物代號、市場代號、過去平均價與交易量、星期等，預測未來 1–7 個交易日的每公斤批發平均價。家庭校正另用自家同品項、同通路、有重量的實付單價，學習批發價至該通路實付價的差額或倍率。合計預算由各品項預測與指定重量計算；保留個別品項誤差的相關性，不能把每項上價／下價直接當成未來預測區間。

### 已查到的既有作品，及與本提案比較

1. [陳泯宏，2024，國產大宗蔬菜價格預測模型之比較，臺大官方摘要](https://tdr.lib.ntu.edu.tw/handle/123456789/92775)：2012–2022 批發價格；比較 ARIMA、ETS、TDNN、LSTM，以 RMSE、MAD、MAPE 與方向正確率評估。研究已做價格預測，並指出大幅波動時會失準。全文限校內，這次核對的是官方摘要與方法說明。
2. [陳澤維，2018，臺灣蔬果批發市場價格預測模型，政大官方摘要](https://thesis.lib.nccu.edu.tw/thesis/detail/fe0ccad4dc32570e79ea33c510636780/?seq=2)：分區日均批發價與全台交易量的複迴歸模型；已考慮前期價格、量、氣象、星期與盛產季節。不能把加入天氣／分區說成差異。
3. [台灣蔬果生鮮，開發者 Google Play 頁](https://play.google.com/store/apps/details?hl=zh_TW&id=app.doitwell.agriinfo)：2026-08-05 更新，已提供近期便宜品項、漲跌、歷史行情、公斤／台斤換算、粗略預估零售價。不能把查價、單位換算或提供零售價稱為特色。
4. [MacLachlan 等，2025，Adaptive food price forecasting improves public information in times of rapid economic change](https://www.nature.com/articles/s41467-025-61660-x)：美國整體食品 CPI、自適應 SARIMAX 與預測區間。這是既有方法比較來源；不拿美國價格當台灣訓練資料，也不能宣稱食品預測區間本身是新方法。

**差異化假設**：已核對作品的摘要／公開功能以批發品項、區域價格或整體物價為對象，未呈現「少量指定家庭、指定零售通路校正 + 固定採買籃的區間覆蓋率與超支漏報」這組評估。專題的可測特色限於這個完整組合；查詢未命中不代表全球首次。

### 家庭資料與最小對照

- 家庭資料：同一家／同一通路、同品種的日期、重量、實付總額。先手動登錄，避免同時開發收據 OCR。單顆價格且沒有重量的資料不能直接與每公斤批發價校正；特價、不同品質、半成品需分開。
- 採集試點建議（工程估計，非統計保證）：跨 6–8 週，每週約 2 次，共 12–16 次採買；固定 3–5 個反覆購買品項。以較早約 8–10 次校正，後面至少 4–6 次只測試。不是要求每次都買齊所有品項，但各品項要有跨日期可比觀測。單張收據只能登錄，無法估波動或獨立測試；這個量也只支持初步效果，季節／颱風可靠性需更長的實際採集。
- 對照 A：只用歷史公共資料預測批發價，以固定零售倍率推算。
- 對照 B：相同公共模型，加少量自家收據估通路／品項的校正。
- 對照 C：上一回購買價與近期移動平均，不引入複雜模型。
- 按採買日期向前切分，校正用前段；之後的新採買週獨立測試。不得用測試週的零售收據回填預測。
- 主要評估：總金額絕對誤差、預測區間實際覆蓋率與寬度、超出預算但系統未提示的比例；另分價格大幅變動週、休市前後。具體目標數值由試點決定，不預告一定改善。

**瓶頸／保留條件**：公開資料只有批發行情，無法證明自家零售價。若使用者不願記同品種重量與實付價，應把此家庭題降為公共資料試驗，不推稱可精準預測自家支出。少量收據能否有足夠可比筆數也是尚待測的條件。這題可以先用台灣公開資料訓練，家庭部分再校正，但收據不足時需清楚分開兩種成果。

## 曾評估 F02，後續查重後撤下：多人紙本採買字詞校正

整合審查新增 [MetaHTR2021](https://openaccess.thecvf.com/content/CVPR2021/papers/Bhunia_MetaHTR_Towards_Writer-Adaptive_Handwritten_Text_Recognition_CVPR_2021_paper.pdf)多作者／少樣本適應、[Handwriting Style Mixture Adaptation](https://ieeexplore.ieee.org/document/8270097/)混合作者筆跡，以及 [UCL-MHTR](https://www.sciencedirect.com/science/article/pii/S0957417425023590)持續學習／遺忘。它們不完全等於本家庭案例，但原差異只剩換家庭與校正數量，不足以推薦；另有授權衝突及未核對writer ID。下文保留當時提案供追溯，F02不列本輪使用者選項。

**用途與範圍**：拍照辨識家人手寫採買品項。最小版先限 20–30 個固定繁體品項，只辨識事先切好的單字／字詞，避免同時承諾整張自由版面辨識、數字單位與自動下單。

**公開訓練資料**：[南臺來源、AI-FREE 改作的繁體手寫資料](https://github.com/AI-FREE-Team/Traditional-Chinese-Handwriting-Dataset)，常用版 4,803 字、250,712 張 50×50 圖像；完整版本 13,065 字、684,677 張 300×300 圖像。單字字形標籤是真實檔名，沒有購物清單、品項欄位或已核對的作者身分標籤，故不能說公共模型已訓練整張清單或家庭作者辨識。

**此次取得狀態**：已查原作者 GitHub data 清單、四個 ZIP 的檔案大小；第 1 個 38,525,034 bytes ZIP 的 Range GET 返回 HTTP 206，讀 2,048 bytes，確認 PK ZIP header、內含 `cleaned_data(50_50)/齷_42.png` 與 PNG/IHDR 50×50。只確認下載與壓縮檔片段，不是已讀完所有圖片／分布。README 寫 CC BY-NC-SA 4.0，GitHub 授權識別為 CC BY-SA 4.0；學術非商業使用先採較嚴格的署名、非商業、相同方式分享要求，外部發布前仍需核對原作者授權。

**實際查到的既有作品**：

- AI-FREE 原專案已做 CNN 繁體單字與 Web 訓練辨識。
- [2016 原作者論文：Online and Offline Handwritten Chinese Character Recognition](https://arxiv.org/abs/1606.05763) 已做新作者的無監督筆跡適應。
- [2016 原作者論文：Writer Code Based Adaptation](https://sprateam-ustc.github.io/Publications/zirui2016icfhr.pdf) 已做離線中文字與 writer code 適應，不能把照片／離線個人化本身說成差異。
- [蒙恬原廠](https://mobile.penpower.net/diamond_tch.html) 已有筆跡學習、聯想字詞庫。
- [2022 mySmartCart 原論文](https://ijai.iaescore.com/index.php/IJAI/article/view/21816) 已將語音、手寫照片、NLP 與購物清單結合；[2026 Petatto 開發者 APP 頁](https://apps.apple.com/us/app/petatto-shopping/id6771294759) 也提供手寫購物便條 OCR。

**值得測的差異限於**：同一家庭 2–3 位作者輪流修正時，比較「共用校正模型」「每人獨立校正」「公共模型不校正」的人工修正次數、學習 5／10／20 字後的錯誤下降，以及學某位家人後對其他家人的退步。這是家庭維護成本與相互干擾的實驗；不是新 OCR、不是第一次筆跡校正，也不是第一次照片轉購物清單。尚未在已讀作品中看到相同低修正預算、家庭輪流、舊家人成績保留的完整評估，但未命中不等於無人做過。

**家庭資料／主要瓶頸**：要 2–3 人各寫 20–30 個品項，在不同日期／筆記紙上重複 3–5 次，手工切字及確認標籤。固定食材字表可能只需公共資料的一部分。以原紙張／日期分組，不能把同張照片的切字分到訓練和測試。讀到的公共資料未核對 writer ID，故公共資料只作起始模型，家庭個人化以有作者與日期的新資料驗證。若只能取得一人少量字圖，沒有多人相互干擾問題，則不保留此題的特色。
