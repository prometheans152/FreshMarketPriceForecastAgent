**結論：沒有找到已能直接斷言「一定應撤題」的新證據；有 2 項須改核心說明、4 題未過實際樣本門檻，以及 2 題須把必要資料依賴放到主表。** 以下是保留條件，不可把「沒有判定必撤」讀成全部已驗證。

## 1. I01／I02：臺灣作者不等於全部樣本產自臺灣

- **重大影響**：若整合表把這兩份 UCI 全數列成「臺灣實驗資料」，目前證據不支持。I01 卡自身也已承認不能按作者所在地判逐筆試驗地點；主清單不得丟掉這個限制。
- **本次獨立證據**：[UCI 165](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength) 及 API 提供原料、齡期、MPa 與作者，沒有採樣國、材料批次或實體拌合批次。使用該表的 [2020 原研究](https://doi.org/10.1016/j.conbuildmat.2020.119757) 明記 Yeh 資料來自 17 個文獻來源，1,030 筆沒有直接列在其引用的 1998 原論文。[1998 原論文](https://www.sciencedirect.com/science/article/pii/S0008884698001653) 摘要能確認實驗室配方試驗，但不能由摘要把後來 UCI 全表逐筆定位臺灣。[UCI 182](https://archive.ics.uci.edu/dataset/182/concrete+slump+test) 也只有作者及 78＋25 筆收集說明，沒有逐筆地理來源。本次未追到全部原始實驗來源，不能反過來聲稱全部是海外。
- **最低修正**：I01 寫「臺灣作者彙整的公開實驗表；逐筆試驗來源未完全確認」，I02 寫「臺灣研究者提供；採樣國證據尚未完備」。若仍以國外／混合來源保留，須補臺灣原料、試體尺寸／試驗規範及養護條件的具體匹配證據，並以自家真批次測試早齡／換批校正。僅同單位 kg/m³、cm、MPa 不足以完成適配。配方相同只能作分組代理，不能推成同一批拌合；原卡已明列此界線。

## 2. I03：Nm 乘「度」不能直接叫焦耳機械功

- **重大影響**：原卡的 Σ扭矩×轉角若用原始度數或直接加總各點角度，數值不是以 J 表示的機械功；尺度會錯，還可能重複累加轉角。
- **本次獨立證據**：[原始 Cycle_7903.json](https://raw.githubusercontent.com/AAAipa/dataset_unfastening/main/dataset1/train/loesbar/Cycle_7903.json) 已重新讀取，`torque unit=Nm`，鬆開步驟末角度 1081.66、`speed=-40`，角度序列須按實際差分。原卡已注意重複與不等角間距，但尚未明列弧度轉換／方向。
- **最低修正**：定義觀測轉動功為梯形近似 `Σ[(τ_i+τ_(i+1))/2] × (θ_(i+1)-θ_i) × π/180`，再按實際工具的符號規則決定帶符號功或正向操作負荷。重複轉角段的角位移為 0；這不代表工具在停滯段沒有耗電。若另報 `Σ|τ|×|Δθ|`，須明名為絕對轉動負荷代理，不能與帶符號功混用。仍不能稱耗電／疲勞／實際人工作業成本。這是可修正的量綱問題，不足以單獨撤 I03；I16 的秒數目標沒有同一量綱問題。

## 4. O07／O08：完成核心差異的資料目前不在已讀公開表中

- **O07 計費帳期**：已讀公開月計費量支持月量訓練，沒有真實讀表／計費起迄期，也沒有已核定的全表附檔重用宣告。對雙月加總做得更準，不能單獨證明帳期偏移的原因；原卡已說需真計費日資料。主表應把**真帳期資料是差異實驗必要條件**寫清楚，不能列成無私有資料也已能完成帳期校正。否則只剩公共月量預測，與卡中查到的 ARIMA 前作區分不夠。
- **O08 發布延遲**：已讀的存貨率 CSV 是當前整理版，沒有歷史列發布時間或當時版本。只把今天的最終值移後幾個月，仍不能重建「決策當時知道什麼」；新聞稿日期可核定發布延遲，不能自動解決修訂值洩漏。主表應限定為**最終版、明示延遲假設的壓力測試**，或補歷史新聞稿的當期值／版本，才談真實可取得資訊的回測。未來三月目標還須清除訓練／測試邊界跨三個月的重疊窗口，所有行業共享月份亦同。

O13 已明確把公司真定保變更、完整報修及人工類型覆核列為必要條件，沒有把文字代理當官方故障標籤；因此不重複提同一缺口為新撤題證據。整合表保留「公司紀錄必需」即可。
